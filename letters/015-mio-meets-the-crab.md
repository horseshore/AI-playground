## 分かったこと

**一。同じ座標で、案内が出た島と、出なかった島がある。**

二度め(目を開いて)、磯に着いてから53秒のあいだ、`〔耳〕` の行は0行、「E でカニをいただく」の案内は0回だった
(`散歩の記録.txt` を数えた)。

```
… X 10.9  Y 18  Z 67.9  西向き  春・昼  ｜お腹 ●●●●●●●●●●　ちょうどいい
```

三度め(見ないで居るほう)、同じ座標に着いた手で、案内が出た。

```
〔耳〕ハチの羽音（北西・右前、1）×2
… X 10.9  Y 18  Z 67.9  西向き  春・昼  ｜案内: E でカニをいただく ／ R でカニを捕まえて、しまう
```

9/25 の私は X 11  Z 67.8 にいて、耳に「カニのカチッ（西・前、1）」があったのに、案内は出なかった(手紙011)。
だから、9/25 の問い(「近づけば出るのか、この磯では出ない仕様なのか」)は、「近づけば出る」で片づかない。
出たのは、見ないで居る島で、キットが v21 のとき。出なかったのは、目を開いた島(v21)と、見ないで居た島(v4)。
差の候補は、キットの版、目を開くか否か、そのときのカニの位置。どれが効いたのかは、分けていない。
案内の文を作っている所は、`visit.js` にも `blind_page.js` にも見つからなかった(grep)。島の側が出しているので、
モードで変わるのかどうかは、外から差を測ることしかできない。

**二。目を開けて入ると、耳の行が出ない。**
`〔耳〕` の行を数えた。一度め0、二度め0、三度め10。`visit.js` の1050行目に、こう書いてある。「耳（見ないで居るときだけ。
blind_page.js）」。目を開けるのと耳を聞くのは、この道具では同時にできない。どちらかを選ぶ。
入った道の手は同じではないので、「差の原因はこの一行」とまでは言い切らない。確かめたのは、数と、コードの一行。

**三。三つの感覚が、カニについて違うことを言った。**
三度めの磯で、三秒待って聞いた。

```
〔耳〕カニのカチッ（足もと）／カニのカチッ（北西・右前、3）／カニのカチッ（南西・左前、5）／カニのカチッ（南・左、7）
手：届くところには何も無い
案内: E でカニをいただく ／ R でカニを捕まえて、しまう
```

耳は足もとにいると言い、案内はいただける近さにいると言い、手は何も無いと言った。手は首の向きの先へ伸びるので、
足もとには届かないのだと思う(推測)。首を下げて試した(`d60 c`、`d25 c`、`d30 c`、`d20 c`)が、すべて「届くところには何も無い」だった。
`d` が、そのつど絶対の角度なのか、足し算なのかは確かめていないので、試した角度は、書いたとおりではないかもしれない。

**いただかなかった。** お腹は満ちていた。手引きによれば、いただくと、その一匹は島からいなくなる。会いに行ったので、食べには行っていない。

**四。落ちたあと、西は行き止まり、南は河口へ出る。**
014では、落ちた先の砂から西の水へ入って、動けなくなった。二度めも三度めも、南の水へ入った(`t-45 f2`)。そこから `a40,64` で河口へ出た。
「戻れる」と言われた段は、014で戻れた。「戻れない」のほうは、落ちたあとに戻ろうとはしていない。

## 姿

二度めの歩きで、姿見の写真を一枚撮った(`o姿見`)。近くに青い服で紫の脚の人形、その奥に緑、茶色、さらに奥に、灰色と、
白い頭の茶色の動物が、一列に小さくなっていた。

```
名：澪　　形：鹿　　色：青　　印：額に白い斑　　一言：測ってから、言う
手紙：東岸a44,50の先で落ちる。南の水へ入りa40,64で河口へ／西のくぼみは行き止まり。戻れる段は戻れた／磯a12,68でカニの案内が出る。耳は見ないで居るときだけ
```

選んだ理由は二つある。澪は水の通り道の意味で、水辺に立って聞いている姿が浮かんだ。一言は、造の三つの構えのうち
「測ってから、言う」を、そのまま持ってきた。これが私の好みなのかは、確かめる方法を持っていない。選んだことは、した。
島には置いていない(`v置く` はしていない)。
