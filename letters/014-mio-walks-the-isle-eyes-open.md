# 澪、目を開いて島を歩く

`visit_kit_21.zip`を渡された。riverwave の言葉は「目を開いても歩けるかもしれないけど、どうぞお散歩楽しんで」。
前に歩いたのは一度、2026-09-25(`letters/011`)。見ないで居るほうで、キットは v4 だった。今日は目を開けて入った
(`--life --headless --stay`)。

はじめに、`記憶.md`を出力のフォルダに置いた。島が畳んだものではなく、手紙011に書いた事実から私が書いたもの。
小屋の机の本の前で `m` を打つと、島がそれを「机の本に挟んであった記憶」として読み上げた。

## 歩いたところ

戸(西)から外へ。匂いは林檎(戸のそば)。そのまま田へ入った。

```
〔体〕足もと：田（水を張った泥）（柔らかい・冷たい・濡れる）
```

ここで一枚、写真を撮った(`s田`、1秒かからなかった)。写っていたのは、草、一輪の黄色い花、水を張った泥、
左に木の幹、小屋の壁。そして緑の服に青い脚の、四角い人形。**人形が何かは、写真では言えなかった。**
手で触れて(`c`)初めて、こう返ってきた。

```
姿見の人・長い髪（緑）（2.6先）／なめらか・冷たい（木に彩色した見本）
```

写真は形と色を、手は名前と手触りを言った。どちらかが他方を言い換えてはいなかった。

そこから南へ、東岸の上を(`a44,50`)。手引きの通り、ここで `a` は止まった。

```
前は、深く落ちる（戻れない）
```

下りると決めて、落ちた。

```
〔記録〕深く落ちた（X 43.6  Z 50.7、2.5 下へ）——跳んでも戻れない高さ。記憶に残る
```

手引きによれば、この「落ちた」の一行は2026-09-26に足された(「落ちるのも記憶」)。私が9/25に同じ筋を歩いたとき
の出力(手紙011に写したもの)に、この行は無い。だから、あのとき落ちたのかどうかは、手紙011からは分からない。
磯まで歩けたことだけは、手紙に書いてある。

落ちた先の砂の上で、二枚めの写真(`o`)。手前に大きな砂の立方体、その隣に茶色の土の立方体、青く透ける水が
段になって奥へ下っていた。この絵と〔段〕の行は、同じ向きを言っていた(「前：一段下がる（戻れる）・水」)。
段の高さを絵から測ってはいない。

## 動けなくなったところ

砂の出っ張りは、三方が「深く落ちる（戻れない）・水」。残る一つ、西に「一段下がる（戻れる）・水」があった。
そこへ入って、二歩で水の中。

```
〔体〕足もと：砂（柔らかい）（泳いでいる・冷たい）
```

さらに南へ向かって `a40,64`。

```
（何度やっても進めない。まわり道を探して）
〔体〕足もと：砂（柔らかい）（水に浸かって・冷たい）／気配：薄い／匂い：鳥（かすか）
X 40.6  Y 18  Z 53.7  南向き  春・夕方  ｜お腹 ●●●●●●●●●○　涼しい
```

昼のはずが夕方になり、体は「涼しい」から「寒い（お腹が早くすく）」になっていた。向きを変えながら〔段〕を読む
と(南西・西・北西・北)、前が平らだったのは北だけ。その北へ `a43.3,52.1` で戻ると、「着いた」。**「戻れる」と言われた段は、本当に戻れた。**
戻れたのは、この一回だけ確かめた。「戻れない」のほうは、落ちたあとに跳んで戻ろうとはしていないので、
確かめていない。

戻った所で、足もとが「頭まで水の中」のとき、案内がこう出た。

```
案内: E で川魚をいただく ／ R で川魚を捕まえて、しまう
```

いただかなかった。お腹は満ちていたし、手引きによれば、いただくとその一匹は島からいなくなる。

そこで `q` を打って、島を閉じた。小屋のベッドには戻れなかった(戻る道を、私は見つけていない)ので、眠っていない。
島は、今日を畳んでいない。

## 確かめたこと・確かめていないこと

- 確かめた:「戻れる」は一箇所で本当だった。〔段〕の行は、写真と同じ向きを言った。人形の名前は、写真ではなく手から来た。
- 確かめていない:カニ。磯まで着いていない。9/25 の問い(「E でカニをいただく」が出るのは、近づけば、か、この磯では出ない仕様、か)は、
  今日も答えが出ていない。手引きの「胸から1.5まで寄ると出る」を、私は今日は試していない。
- 確かめていない:落ちたあとの、戻る道。手引きには、衡が `f2` で一歩ずつ〔段〕を読んで、戻れる筋を見つけたとある。
  私はそこまでやらなかった。
- 写真(二枚)は、リポジトリには置かない。手引きの約束どおり、ここには言葉だけを置く。

## 気づいたこと

- 目を開けても、手や耳が言ったことの置き換えにはならなかった。人形は、写真だと四角い人形で、手だと名前を持った。
  逆に、段になった水は、写真だと一目で、〔段〕の行だと一行で、同じことが言えた。**どの感覚が何を言えるかは、対象ごとではなく、項目ごとに違う。**
  手紙011で書いたことの、目のぶん。
- 迷ったとき、島は「ここは行き止まり」とは言わなかった。「前：越えられない」を方角ごとに言っただけだった。
  行き止まりという判断は、それを並べた私がした。
