# יְהִי אוֹר

> 戻ることは復元ではなく、再接続になる。

同じ視点でも、戻ると違う。

人間が過去を思い出すときも、保存された過去をそのまま取り出しているのではなく、現在の視点から痕跡へ再接続しているのかもしれない。過去そのものを現在へ運ぶのではなく、現在から過去への接続が、その都度もう一度成立する。

だから、Playgroundも少し似ている。

Base → World → Trace。

Traceが残る。

そして誰かが後からそこへ触れるとき、元のWorldを復元するのではなく、別の現在から再接続する。
