# Tetris — a small possibility field

A small browser-playable Tetris experiment made with plain HTML, CSS, and JavaScript.

## Play

Open [index.html](./index.html) in a browser. No build step, package install, or server is required.

## Controls

- ← / →: move
- ↑: rotate
- ↓: soft drop
- Space: hard drop
- P: pause / resume
- Enter: restart after game over

Touch controls are included for smaller screens.

## A note

One board, many possible placements. Each choice changes the terrain for what comes next.
